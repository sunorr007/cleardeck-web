Roadmap

ClearDeck is an unreleased 0.1.0 from a small team. This page lists what already exists, what still has to happen before a first public release, and what is merely being considered — with no dates.

  • v0.1.0
  • Android 10 – 17
  • unreleased
shipped

Shipped in the current build (0.1.0)

  • Five built-in function modules, 446,322 entries in total, covering the domain layer and the deep URL layer.
  • Per-app live and history views: live connections, attempts, blocked counts and time since last seen.
  • Access log with Block and Allow actions that become rules scoped to an app.
  • Import of rule files (.yaml/.txt/.mrs) and HTTPS subscription links that can be refreshed.
  • Deep inspection: certificate install, app scope, Wi-Fi-only mode and a content inspection limit.
  • Dashboard statistics: traffic, blocked breakdown by module, destinations grouped by registrable domain, top 5 apps, DNS resolvers and intranet IP.
  • Encrypted DNS with a resolver you can change at any time.
  • Power saving mode — one switch that widens the sampling intervals and pauses deep inspection.
  • CSV export of the access log.
  • Four store builds (Google, OPPO, Huawei, Xiaomi). Identical features; the difference is only the analytics SDK.
next

Before the first public release

These are real gaps we can point at, not a wish list.

  • Finish the in-app privacy policy and user agreement, which are still placeholder text.
  • Add release signing configuration — without it a release build cannot be installed.
  • Publish the source repository — GPL-3.0 requires it before distributing binaries.
  • Publish a contact address; the app currently shows a placeholder.
  • Ship a first public APK and the store listings that go with it.
considering

Being considered

Not committed and not scheduled. These are ideas only, and they may not happen.

  • More interface languages. The app ships English and Simplified Chinese only.
  • Wear OS and TV support.
  • Layout work specifically for tablets.
about dates There is no timeline on this page, and nothing under “being considered” is scheduled. ClearDeck is a 0.1.0 and has not been released; items only leave these groups when they are actually done and shipped.
