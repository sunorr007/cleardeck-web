Privacy and trust

When a network tool says "we do not upload your data", that sentence only means something if you can check where the data goes. This page lays out every path.

Where every piece of data goes

Data Where it goes Detail
Your network traffic never leaves the device judged and forwarded locally; there is no server that relays or stores your traffic
Access records on the phone only cleared when protection stops; exportable to CSV that stays yours
Rule lists one manifest request at launch only version numbers and download URLs, with no device identifier or account; module packages download only when their version changes
Legal documents fetched from this site when opened the server can see your IP, the time and the request path; a bundled local copy is used if the network is slow
Analytics and crash reports only after you agree usage statistics plus crash and performance reports, processed by Umeng; never the content of your traffic

Rule downloads are HTTPS-only

Imported rule links must be HTTPS addresses. The reason is plain: a rule list is the firewall rule, so a cleartext download would let a man in the middle rewrite what you block.

Analytics and consent

The privacy notice on first launch is a hard gate: decline and the app will not run. What is collected after you agree is itemised there rather than buried in a long document.

What is collected usage statistics, crash and performance reports
When it starts only after you accept the privacy notice; the pre-initialisation stage collects nothing
What is never collected the content of your traffic
note "Traffic content is never collected" and "usage statistics are collected" are two different statements, so we write them separately. The first is how the product works. The second is optional and only begins once you agree.

Deep inspection is the one feature that can see content

inherent to the technique It has to be said plainly: once deep inspection is on and the certificate is installed, ClearDeck is technically able to see the content of the connections it intercepts. So it is off by default, and when on it is bounded three ways: only the apps you tick, optionally Wi-Fi only, and only the first 256 KB of each connection before the rest passes through.
Deep inspection setup

What it cannot do

  • With deep inspection off, ClearDeck never sees content — the domain layer gets a hostname and nothing more.
  • There is no ClearDeck account system, so there is no "cloud sync" feature that could carry data off the device.
  • There is no remote node, so no server relays or stores your traffic.
