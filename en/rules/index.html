Bundled rule lists

ClearDeck ships 446,709 ad, tracker and malware rules inside the app. A fresh install needs no list download, and the app keeps them current.

  • 446,709 entries
  • 9.8 MB
  • v202610261543
  • 2026-10-26

The five function modules

They split by what can actually be decided: hosts a hostname settles, and hosts that need the full address.

Module Layer Entries What it covers
Ad blocking Domain 92,299 ad hosts, blocked for every app · membership module, off by default
Tracker blocking Domain 129,994 tracking and analytics hosts, blocked for every app · free, on by default
Deep ad blocking URL 1,925 ad slots that need the full path — requires deep inspection · membership module, off by default
Deep tracker blocking URL 9,610 tracking links that need the full path — requires deep inspection · free, on by default
Malicious site blocking Domain 212,881 malicious and phishing hosts, from a feed that carries no ads · membership module, off by default
Total 446,709 9.8 MB (combined size of the rule files in the package)
membership and defaults The restricted modules (ad blocking, deep ad blocking and malicious site blocking) require a membership and are off by default. Membership is available in the Huawei, OPPO and Xiaomi builds, and the first time you enable any restricted module you get a 14-day trial. Tracker blocking and deep tracker blocking are free and on by default. The Google build includes no membership purchase.

Where the lists come from

All of them are public community lists, taken per purpose; the sources are listed in the table above.

Source Used for
EasyList ads
EasyList Ad Servers ads
217heidai/adblockfilters ads
AWAvenue Ads Rule ads · trackers
EasyPrivacy trackers
AdGuard Tracking Protection trackers
Hagezi Threat Intelligence Feeds (TIF, mini) malware

A connection is counted under one module

The blocked breakdown counts connections: whichever kind of rule caught a connection owns the count, and each connection is counted once — which is what makes the donut’s categories meaningful. It counts blocking events, not unique hosts. Individual hostnames can overlap across lists (different subdomains of the same domain can sit in different lists), but each connection is attributed once, to the rule that matched first.

The domain layer and the URL layer stack rather than replace each other: URL rules need deep inspection switched on and the certificate installed, and when they are not, the domain layer keeps working as before.

Offline, and the build never touches the network

note The lists are generated in a **separate offline project** and committed to the repository. A normal build makes no network requests, so 446,709 rules are already present the moment you have the package. Current version `202610261543` (2026-10-26).

And the rules keep themselves current

The five bundled modules are not frozen at install time: their lists are published separately through a download channel, and the app checks for a newer version every 3 days. Automatic downloads happen only on unmetered networks; the check for updates button at the top of the modules page lets you check by hand at any time without that restriction. Only modules whose version is newer than the one on the phone are downloaded, and each download is checked against its size, its sha256 and its version stamp before anything is used — so the worst case is that you keep the lists you already had.

Add your own lists

When the bundled ones are not enough, import your own: `.yaml`, `.txt` and `.mrs` are supported, with the kind detected on import (domain list, IP list, mixed list, or full URL matching) and the action (block or allow) shown before you commit. Imported files have no size cap — the 32 MB limit applies to subscription downloads only.

The limitations, stated

False positives happen
These are community-maintained lists and any of them can over-block. When an app "mysteriously cannot connect", check its access record and exclude it with an allow rule before concluding the app is broken.
Domain grouping is approximate
Grouping destinations by registrable domain uses a fixed table of common suffixes rather than the full Public Suffix List, so an unusual suffix can group imperfectly.
The malware list carries no ads
The threat feed itself contains no ad or tracker hosts, so turning "malicious site blocking" off cannot leak ads back in — ads are always the ad module’s job.
