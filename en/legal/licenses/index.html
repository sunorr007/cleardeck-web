Licences

Attribution for ClearDeck, the community rule lists it bundles, and the third-party components it is built on.

This page is attribution. It says what ClearDeck is built from, where the bundled rule lists come from, and what each licence allows. Getting this right is both a licence obligation and a matter of honesty — so where we could not confirm a licence, we say so rather than guess.

The app itself

ClearDeck is licensed under the GNU General Public License, version 3 (GPL-3.0), and the source is available under that licence.

It is derived from ClashMetaForAndroid (GPL-3.0) and the mihomo kernel (GPL-3.0). That derivation is why the whole app is GPL-3.0 rather than something more permissive: a work built on GPL-3.0 code must itself be distributed under the same licence.

The app’s NOTICE file records the licence for anti-AD, but it records no licence for the community lists above. We have not written one in for them, because a wrong licence is worse than none. Each project publishes its own terms at its own source, and anyone redistributing these lists has to check there.

The Umeng row applies to the Huawei and Xiaomi builds only. The Google and OPPO builds contain no Umeng code, permissions or manifest entries. That is enforced by module structure, not by a runtime flag.

What GPL-3.0 means for you

In plain terms: you may use, study, modify and redistribute ClearDeck. If you distribute a version you have modified, you must make its source available under the same GPL-3.0 licence. You cannot take this code and ship it as a closed product.

The full licence texts

The complete third-party licence texts ship with the app: open About → Third-party SDK list to read them. This page is a summary, not a substitute for those texts.
