Get ClearDeck

There is no public build yet. This page explains which devices it will run on, how it will be released, and why the honest call to action right now is "notify me" rather than "download".

status

In development · v0.1.0

It is not on any app store, F-Droid or GitHub Releases yet.

What launch will look like

The four store builds

One app, four builds, one per app store. The features are identical; the only difference is the analytics SDK.

Google

no analytics SDK at all — not one line of Umeng code, not one permission

OPPO

no analytics SDK, identical to the Google build

Huawei

includes Umeng analytics and crash reporting

Xiaomi

includes Umeng analytics and crash reporting

Why there is nothing to download yet

  1. The in-app privacy policy and user agreement are still placeholder text and need to be finished before any public distribution.
  2. There is no release signing configuration yet, so a release build cannot be installed.
  3. GPL-3.0 requires that anyone who receives the binary can also get the corresponding source — which means the main repository has to go public first.
what we will not do It will not put a server in the middle. ClearDeck has no remote node and nothing that could relay traffic — that is a property of the architecture, not a setting you have to trust.
