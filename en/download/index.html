Verify the package

Before installing, compare the SHA-256 to confirm you have this build. One command in a terminal:

sha256sum ClearDeck-arm64.apk

Windows (PowerShell): Get-FileHash -Algorithm SHA256 ClearDeck-arm64.apk

Install

  1. Android may block installs from unknown sources. Allow it once for the browser or file manager you downloaded with.
  2. Open ClearDeck and follow the setup to start protection.
  3. Later versions install over the top; settings, your own rules and the access log are kept.
