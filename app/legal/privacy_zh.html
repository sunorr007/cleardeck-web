适用范围与数据控制者

本政策适用于我们通过本应用处理个人信息的行为。本应用个人信息处理的控制者为北京烽鸿科技有限责任公司，联系方式见本政策“联系方式”一节。

本政策不适用于由第三方独立提供的产品或服务。第三方处理者的处理活动适用其各自的隐私政策。

本机网络处理

本应用使用 Android 的 VpnService 在本机建立 TUN 连接，用于查看和判定设备上各应用的网络连接。规则匹配与拦截决定均在本机完成，我们未设置用于中转上网流量的远程节点或中转服务器。

为避免本应用自身的网络请求被自身捕获，本应用会将自身从 TUN 捕获范围中排除。该处理不涉及将您的上网流量内容传输给我们。

我们不处理的信息

我们不会收集、上传或存储以下信息：

  • 您的上网流量内容，包括您访问的网站、应用发出的请求及通讯内容。
  • 您访问的网站或域名清单。
  • 访问记录的内容。
  • 深度解析连接中除“本机拦截或放行”这一判定结果之外的任何内容。
  • 通讯录、短信、照片、文件、精确位置等个人信息。本应用未申请访问上述信息的权限。

规则名单更新

本应用在启动、回到前台以及您手动发起检查时，向我们运营的 cleardeck-dl.fenghongtech.cn 请求规则名单清单，以判断是否存在新版本。

该请求可能在您同意本政策之前发生，因为本应用启动时会执行一次清单检查。该请求不包含应用版本号、设备标识、账号或其他标识信息。我们的服务器会接收并记录 IP 地址、请求时间、请求路径及标准 HTTP 头。

自动下载规则模块包仅在非计费网络下进行。您在功能模块页手动发起检查时，不受非计费网络限制。规则名单下载至本机后，过滤仍完全在本机进行。

使用统计与崩溃分析

仅在华为渠道与小米渠道的安装包中，本应用集成友盟+（Umeng）的 U-App 与 U-APM 组件。

友盟 SDK 在本应用启动时执行不采集数据的预初始化；只有在您同意本政策后，我们才会启动正式采集。收集的信息包括设备型号、系统版本、功能使用统计、Java 与 Native 崩溃信息及 ANR 信息，用于了解设备兼容性与功能使用情况、发现并修复稳定性问题。上述信息由友盟+ 受我们委托处理，其隐私政策见 https://www.umeng.com/page/policy。

Google 渠道与 OPPO 渠道的安装包不集成友盟 SDK，不进行上述采集。

会员服务与支付

本应用在华为渠道、OPPO 渠道与小米渠道提供会员服务。

在华为渠道，支付由华为应用市场处理，我们不接触、不保存您的支付方式、银行卡号或账单地址。为核验订单、绑定会员、支持跨设备找回月费与年费会员以及按设备计算试用期，本应用会向我们的会员服务发送以下信息：华为账号 openId、订单凭证、商品标识、ANDROID_ID 的 SHA-256 哈希值、试用起点。

在 OPPO 渠道，支付由支付宝处理，本应用不接触您的支付宝账号与支付信息：下单内容（订单串）由我们的服务器签名后交给支付宝客户端完成付款。为核验订单、按设备归属会员以及计算试用期，本应用会向该会员服务发送以下信息：订单号、商品标识、ANDROID_ID 的 SHA-256 哈希值、试用起点；为补记个别未到账的付款，还会发送您主动提供的支付宝交易号。OPPO 渠道没有渠道账号体系，会员权益（含永久会员）按设备标识哈希归属本机。

在小米渠道，支付由小米应用商店（应用联运）处理，我们不接触、不保存您的支付方式、银行卡号或账单地址。为核验订单、绑定会员、支持跨设备找回月费与年费会员以及按设备计算试用期，本应用会向我们的会员服务发送以下信息：小米账号 uid、订单号、商品标识、ANDROID_ID 的 SHA-256 哈希值、试用起点。永久会员按设备标识哈希归属购买时的设备。

上述信息仅用于提供会员服务、防止同一订单被重复使用、绑定永久会员至购买设备以及计算试用期。会员数据与访问记录相互独立，会员服务无法获知您访问的网站或访问记录。

深度解析

深度解析为可选功能，默认关闭。开启后，证书在本机生成，不会离开设备；解析过程中看到的内容仅用于在本机作出拦截或放行决定，不会上传。

您可以限定深度解析仅对指定应用生效、仅在 Wi-Fi 下生效，并限制每条连接的最大检查内容（默认 256 KB）。从本机移除证书即可关闭该功能。

信息共享与跨境传输

我们不会出售您的个人信息。除本政策明确说明的情形外，我们不会向第三方提供您的个人信息，但法律法规另有规定或经您另行同意的除外。

如相关处理涉及个人信息跨境传输，我们将按照适用法律的要求履行相应程序并采取必要保护措施。

信息安全

我们采取与本应用功能相适应的技术和管理措施保护个人信息，包括使用 HTTPS 传输、最小化收集范围、将网络过滤与访问记录限制在本机、以及限制内部访问权限。

互联网传输与电子存储无法保证绝对安全。如发生个人信息安全事件，我们将按照适用法律的要求采取处置措施并履行通知义务。

您的权利

在适用法律允许的范围内，您有权：

  • 查阅、复制您的个人信息；
  • 要求更正不准确的个人信息；
  • 要求删除您的个人信息；
  • 撤回您此前作出的同意；
  • 要求我们解释个人信息处理规则；
  • 就个人信息处理向我们提出投诉。

您可以通过本政策“联系方式”一节的邮箱行使上述权利。我们将在法律规定的期限内答复。

撤回同意不影响撤回前基于您的同意已经进行的处理活动的效力。卸载本应用后，本应用将不再收集使用统计与崩溃信息。

未成年人保护

本应用不面向未满十四周岁的儿童。我们不会在明知的情况下收集未满十四周岁儿童的个人信息。如我们发现在未获得监护人同意的情况下收集了儿童个人信息，将依法删除。

政策变更

我们可能根据法律法规、业务或技术变化更新本政策。更新后的政策将在本网站发布，并更新文首的版本号、最后更新日期与生效日期。涉及您重大权益的变更，我们将通过本网站公告或其他合理方式通知您。
