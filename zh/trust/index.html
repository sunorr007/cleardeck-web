隐私与信任

一个网络工具说「我们不上传你的数据」，这句话只有在你能核对数据流向时才有意义。这一页把每一条数据去向摆出来。

数据去向总表

数据 去哪 说明
你的上网流量 不离开设备 判定与转发都在本机完成，没有用于中转或存储上网流量的服务器
访问记录 只存在本机数据库 防护停止时清空，可导出成 CSV 自己留着
规则名单与模块包 启动时请求名单；模块包按需下载 名单请求发生在同意前后均可，只返回版本号与下载地址，不携带设备标识或账号；自动下载仅在非计费网络下进行，手动检查不受此限制
法务文档 同意后打开页面时获取 来自 cleardeck.fenghongtech.cn（GitHub Pages 托管）；服务器可见 IP、时间、路径与标准 HTTP 头；5 秒未完成则使用本地版本
引擎控制通道 仅回环地址 只监听 127.0.0.1，随机端口，每次加载配置换一个随机密钥
统计与崩溃报告 仅华为 / 小米两个包 由友盟 SDK 处理；同意后才开始采集，预初始化阶段不采集；Google 与 OPPO 包不含任何统计代码
会员与支付 华为 / OPPO / 小米三个渠道 华为渠道经华为应用市场支付，OPPO 渠道经支付宝，小米渠道经小米应用商店（应用联运）；发送订单号、商品标识、ANDROID_ID 的 SHA-256 与试用起点，用于核验权益；Google 渠道不含会员购买

本机控制通道

界面和引擎在两个进程里，中间靠一个本机 HTTP 接口通信。这个接口的处理方式值得单独说：

控制通道
绑定地址
127.0.0.1 —— 只接受本机回环连接，局域网里其他设备也连不上
端口
随机分配，不固定
鉴权
每次加载配置都重新生成一个随机密钥 —— 不是写死在代码里的常量
明文放行范围
网络安全配置里只对 127.0.0.1 与 localhost 允许明文，且文件里写明了为什么

为什么把自己排除在外

御流会把自己的包排除在抓取之外。这不是省事，而是因为部分 ROM（华为上实测到）在 VPN 自己的中继 socket 也被自己抓走时会直接断网。这是踩过的坑，不是随手写的例外。

两个协议族都抓

同时接管 IPv4 与 IPv6。如果只抓 IPv4，任何走 IPv6 的连接都会绕开全部规则、一条也拦不住 —— 那样规则表再大也没有意义。

规则下载只允许 HTTPS

订阅链接只接受 `https://`。原因很直接：规则名单**本身就是防火墙规则**，明文下载意味着中间人可以改写你的拦截表。除此之外，下载有连接超时、体积上限（32 MB），并且关闭了 SSL 重定向跟随，避免 https 被降级成 http。

统计与同意

首次启动的隐私说明是一道硬门槛：不同意就无法使用。同意之后收集的内容在页面里逐条写明，而不是塞进一段长条款。

华为包 / 小米包 包含友盟的使用统计、崩溃与性能报告
Google 包 / OPPO 包 不含友盟代码、不含友盟权限、不含友盟清单条目
怎么保证的 靠模块结构保证 —— 这两个包根本不依赖 :core-analytics-umeng，不是靠运行时开关判断
note 「不收集流量内容」和「收集使用统计」是两件事，我们分开写。前者是产品架构决定的，后者是可选的、由你同意才开始的。

深度解析是唯一能「看到内容」的功能

这是这项技术的固有性质 必须讲清楚：开启深度解析并安装证书后，御流在技术上**有能力看到被拦截连接的解密内容** —— 这是这项技术本身决定的，不是实现方式的选择。所以它默认关闭，而开启后有三层限制：只对勾选的应用生效、可以限定仅在 Wi-Fi 下、以及每个连接只检查前若干 KB（默认 256 KB）就放行。
深度解析的安装步骤

它做不到的事

  • 深度解析关闭时，任何连接的明文内容都看不到 —— 域名层只拿得到主机名，拿不到路径。
  • 没有御流自己的账号体系，所以没有「云端同步」这种会把数据带出去的功能；华为、OPPO 与小米渠道的会员使用各自渠道的账号或订单信息，仅用于订单与权益校验。
  • 没有远程节点，因此不存在用于中转或存储上网流量的服务器；规则名单、法务文档与会员数据的传输方式另列在上表。
