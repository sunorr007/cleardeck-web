第三方 SDK 列表

御流各渠道安装包中会处理个人数据的第三方 SDK，以及本网站使用的第三方服务。

本清单列出御流 Android 应用（以下简称“本应用”）各渠道安装包中会处理个人数据的第三方 SDK，以及本网站使用的第三方服务。本清单与《隐私政策》配套适用。

适用范围

本应用针对不同应用商店发布四个渠道的安装包：华为、小米、Google 与 OPPO。各渠道包含的第三方 SDK 不同，具体内容见下文相应渠道一节。

本清单仅列出会处理个人数据的第三方 SDK。基础开发库（例如网络请求库与界面框架）不在此列。

渠道说明

渠道 包含的第三方 SDK
华为 友盟+（U-App、U-APM）、华为账号与支付组件
小米 友盟+（U-App、U-APM）、小米账号与支付组件（应用联运）
Google 无
OPPO 支付宝客户端 SDK（APP 支付）

初始化与同意

  • 友盟 SDK 在本应用启动时执行不采集数据的预初始化；只有在您同意《隐私政策》后，我们才会启动正式采集。
  • 华为账号与支付组件仅在您打开会员页面或发起购买时使用。

支付与账号组件仅在您发起会员购买或找回会员时调用，会员服务后端处理的数据见《隐私政策》“会员服务与支付”一节。永久会员按设备归属，月度与年度会员可凭小米账号找回。

初始化与同意

  • 友盟 SDK 在本应用启动时执行不采集数据的预初始化；只有在您同意《隐私政策》后，我们才会启动正式采集。
  • 小米支付与账号组件只在您主动发起购买或找回会员时调用，不会在启动时初始化。

Google 渠道

Google 渠道的安装包不集成会处理个人数据的第三方 SDK，不包含统计、广告、推送与崩溃上报组件，也不包含会员购买与支付能力。

初始化与同意

  • 本渠道不含统计与支付组件，因此不涉及第三方 SDK 的预初始化或同意后采集。

OPPO 渠道

SDK 提供方 版本 处理的数据 目的 隐私政策
支付宝客户端 SDK（APP 支付） 支付宝（支付宝〔中国〕网络技术有限公司） 15.8.42 交易与订单信息、设备信息（设备型号、操作系统版本等）、网络信息 在 OPPO 渠道完成会员的购买与支付 https://opendocs.alipay.com/open/01l92q/

OPPO 渠道的会员通过支付宝完成支付。本应用不接触您的支付宝账号与支付信息：下单内容（订单串）由我们的服务器签名后交给支付宝客户端完成付款。

本渠道没有渠道账号体系，会员权益按设备标识哈希（ANDROID_ID 的不可逆哈希，见《隐私政策》）归属本机；该哈希不会传输给支付宝。会员服务后端由我们运营，处理的数据见《隐私政策》“会员服务与支付”一节。

初始化与同意

  • 支付宝客户端 SDK 仅在您打开会员页面并发起购买时使用；本渠道不含统计组件，不涉及同意后采集。

同意前的数据处理

  • 在您同意《隐私政策》之前，本应用不会为统计目的采集数据。
  • 在您同意《隐私政策》之前，本应用会为检查规则名单更新请求一次规则清单，该请求不包含设备标识或账号。详见《隐私政策》“规则名单更新”一节。

会员服务的数据处理

会员服务涉及以下数据处理：

  • 华为应用市场处理支付，我们不接触支付方式、银行卡号或账单地址。
  • 为核验订单、绑定与找回会员以及计算试用期，本应用会向我们的会员服务发送华为账号 openId、订单凭证、商品标识、ANDROID_ID 的 SHA-256 哈希值与试用起点。
  • 上述数据仅用于提供会员服务。会员数据与访问记录相互独立。

会员服务的数据处理

会员服务涉及以下数据处理：

  • 支付宝处理支付，我们不接触您的支付宝账号信息、支付方式、银行卡号或账单地址。
  • 为核验订单与计算试用期，本应用会向我们的会员服务发送订单号、商品标识、ANDROID_ID 的 SHA-256 哈希值与试用起点；为补记个别未到账的付款，还会发送您主动提供的支付宝交易号。
  • 上述数据仅用于提供会员服务。会员数据与访问记录相互独立。

会员服务的数据处理

会员服务涉及以下数据处理：

  • 小米应用商店（应用联运）处理支付，我们不接触支付方式、银行卡号或账单地址。
  • 为核验订单、绑定与找回会员以及计算试用期，本应用会向我们的会员服务发送小米账号 uid、订单号、商品标识、ANDROID_ID 的 SHA-256 哈希值与试用起点。
  • 永久会员按设备标识哈希归属购买时的设备；月度与年度会员可凭小米账号跨设备找回。
  • 上述数据仅用于提供会员服务。会员数据与访问记录相互独立。

数据共享与保留

除本清单与《隐私政策》列明的情形外，我们不会向第三方提供个人信息。

如本渠道包含第三方 SDK，其按提供方隐私政策规定的期限保留数据。如需了解具体保留期限，请查阅相应 SDK 提供方的隐私政策，或通过本清单“联系方式”一节的邮箱联系我们。

您的选择

  • 不同意《隐私政策》时，本应用无法运行。
  • 卸载本应用后，本应用不再收集使用统计与崩溃信息。
  • 如您希望删除会员相关数据，请通过本清单“联系方式”一节的邮箱联系我们。

变更

我们可能根据法律法规、业务或技术变化更新本清单。更新后的清单将在本网站发布，并更新文首的版本号、最后更新日期与生效日期。

联系方式

如您对本清单有任何疑问，请通过以下邮箱联系我们：support@fenghongtech.cn。

适用法律

本清单适用中华人民共和国法律。因本清单产生的争议，双方应协商解决；协商不成的，提交北京市有管辖权的人民法院解决。

本站使用的第三方服务

本网站为静态网站，仅使用以下第三方服务：

服务 提供方 处理的数据 目的 说明
Web Analytics Cloudflare 汇总的页面访问量与来源 统计访问情况 不使用 Cookie，不对单个访客进行指纹识别

本网站不使用广告、社交媒体跟踪或其他第三方脚本。详见《隐私政策》“本网站”一节。
