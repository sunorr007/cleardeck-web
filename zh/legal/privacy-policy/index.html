隐私政策

御流收集什么、从不收集什么 —— 分别说明 Android 应用与本站两部分。

这份政策覆盖两件事：御流 Android 应用和本站网站。两者是分开的，所以我们也分开写。

它的写法是「短而具体」，而不是「长而令人安心」。如果答案是「我们不收集」，就直接写出来。

我们是谁

御流由北京烽鸿科技有限责任公司发布。本政策中的「我们」指这家公司。

第一部分 · Android 应用

唯一完全不碰的东西

你的上网流量内容不会离开这台手机。 御流的过滤在本机完成。架构里不存在远程节点、不存在中转服务器，也不存在任何能把流量转出去的组件 —— 因为它根本没有。你访问的网站、应用发出的请求、通讯的内容，都不会被上传给我们。

这句话不是在承诺我们的意图，而是在描述产品是怎么造的。你可以自行验证：过滤完全在本地运行，每一条数据去向都写在隐私与信任页里。

唯一一处连到我们服务器的请求

内置的规则名单支持在线更新，所以应用会每隔几天向我们自己的一个下载地址问一次 「名单有没有新版本」，有新版本就下载到本机替换。

这是应用唯一一处连到我们服务器的请求，而它不带任何标识信息 —— 请求里只有应用 版本号，我们的服务器因此只看得到你的 IP 与请求时间。它也不改变流量的走向：名单 下载到手机之后，过滤仍然完全在本机进行。

在计费网络（移动数据）下，自动检查只读取上面那份几 KB 的清单来判断有没有新版本， 不会下载任何模块；真正的下载只会在非计费网络下发生。你也可以在功能模块页手动 发起，那次不受这条限制 —— 因为是你按的。

同意后应用会收集什么

首次启动时应用会展示隐私说明，在你做出选择之前不会运行。如果你同意，应用会收集：

内容 用途
设备信息 —— 机型与系统版本 了解应用在哪些设备上能正常工作
使用统计 —— 哪些功能被打开 了解产品的哪些部分真的有人在用
崩溃与性能报告 发现并修复稳定性问题

这些数据由友盟 SDK 代表我们处理。

关于不同安装包

这些收集只编进了华为与小米两个包。

Google 与 OPPO 包里没有任何友盟代码、没有友盟权限、也没有友盟清单条目。这由模块结构保证 —— 这两个包根本不依赖统计模块 —— 而不是靠一个可能被配错的运行时开关。

应用从不收集什么

  • 你的上网流量内容。
  • 你访问过的网站或域名清单。
  • 你访问记录的内容。
  • 深度解析连接中除「本机拦截还是放行」之外的任何信息。
  • 通讯录、短信、照片、文件、位置，以及其他任何个人数据。应用没有申请这些权限。

只留在你设备上的数据

有一部分数据只存在本地，不会上传：

数据 存在哪 什么时候消失
访问记录（哪个应用连了哪个域名，以及判定结果） 手机本地数据库 防护停止时清空；可在停止前导出成 CSV
你的设置与拦截 / 放行规则 手机本地存储 卸载应用时删除
规则名单与流量统计 手机本地数据库 卸载应用时删除

你随时可以在工具 → 导出访问记录把这些记录导出成 CSV 文件。文件写在你自己手机的存储里，不会发给我们。

深度解析与证书

深度解析是一个可选功能，默认关闭。它按请求的完整地址匹配规则，而不只是主机名，因此需要安装一次御流证书，手机才会把连接展示给应用看。

  • 证书在你的设备上生成，不会离开设备。
  • 安装用户证书意味着御流在技术上有能力看到它所拦截连接的解密内容。这是这项技术的固有性质，不是设计上的取舍。
  • 解析过程中看到的内容只用于在本机做出拦截或放行的判断，不会上传。
  • 你可以把深度解析限定在指定的应用、限定仅在 Wi-Fi 下生效，并限制每条连接最多检查多少内容（默认 256 KB）。

从手机里移除该证书即可关闭这个功能，其他一切不变。

你的选择

  • 不同意隐私说明，应用就无法运行。产品依赖这些反馈来维护，所以我们不提供关闭收集的版本。卸载应用会立即停止全部收集。
  • 卸载应用即视为撤回同意。

未成年人

本应用不面向儿童，我们不会在知情的情况下收集儿童的数据。

第二部分 · 本站网站

网站是纯静态站点，没有登录，也几乎没有可收集的东西。

上线通知名单

如果你在上线通知表单里填了邮箱，我们会存下：

存储内容 用途
你的邮箱地址（统一转小写） 在上线时通知你
你提交时页面的语言（en 或 zh） 让通知用对的语言发出
表单在哪一页 了解大家实际是从哪些页面找过来的
提交时间 基本的记录管理

整条记录就这些。我们只用它在上线时发一条消息。没有推广邮件，没有营销名单，也不会出售或分享给任何人。

名单存在一个数据库里，网站使用的那把公开密钥只能写入、不能读回，所以别人无法通过网站读到你的邮箱地址。

如需删除你的邮箱，请用本政策末尾的联系方式联系我们。

访问统计

本站使用 Cloudflare Web Analytics，它不使用 Cookie。它只报告汇总的页面访问量与来源，不设置 Cookie、不对单个访客做指纹识别、也不跨站跟踪你。因为没有 Cookie 也不涉及个人数据，所以本站没有 Cookie 同意横幅。

我们不使用 Google Analytics、广告像素、社交媒体跟踪器或任何其他第三方脚本。

托管

本站托管在 GitHub Pages 上。与任何网站托管方一样，GitHub 会以托管服务提供者的身份处理为返回页面所必需的技术数据（例如你的 IP 地址）。那部分适用 GitHub 自己的隐私声明。

没有 Cookie

本站不设置任何自己的 Cookie。你的语言选择和扫描线效果开关存在浏览器的 localStorage 里，只留在你的设备上，不会传给我们。

政策变更

如果这份政策有变更，顶部的「最后更新」日期会一起改。重要变更会在更新日志里说明。

联系方式

联系方式尚未定稿，会在第一个公开版本发布前补充。在此之前，请通过项目的 issue 反馈。
