功能

御流是一个功能范围明确的应用。这一页按应用本身的顺序，把它的每一项能力讲全 —— 下面写到的功能都已经在 0.1.0 的构建里实现。

  • 446,322 条内置规则
  • 5 个功能模块
  • Android 10 – 17
  • 免 root

拦截分两层

御流把五个规则模块装进安装包，装完即可离线使用 —— 之后它们还能在线更新，且只下载版本真的变了的模块。其中三个是域名列表：连接指向某个域名，域名在名单里，这条连接在离开手机之前就被拒绝。

另外两个是 URL 列表，只有在开启深度解析之后才生效 —— 判断它们要读完整地址，而不是只看域名。

模块 层 条目数
广告拦截 域名 86,171
行为跟踪拦截 域名 124,994
深度广告拦截 URL 1,596
深度跟踪拦截 URL 9,563
恶意网址拦截 域名 223,998

合计 446,322 条，在安装包里约占 11.8 MB。

两个 URL 模块默认是开启状态，但在深度解析打开之前它们显示为「已暂停」，页面会给你一个一键前往开启的入口。

三个域名层模块对每个应用生效 —— 界面原话是「对所有应用拦截这个名单里的域名」；两个深度模块的范围可以另外限定（见下文深度解析）。关闭某个模块会先弹确认，并说明这个名单里的域名将不再被拦截。

按应用看清流量

在仪表盘点「活跃连接」，就进入应用列表。列表有两个页签：实时活动显示此刻连着的连接数，访问历史显示每个应用尝试过多少次、被拦截过多少次，以及最后一次是多久以前。

点进一个应用，会看到上传 / 下载 / 已节省三个统计格、拦截构成卡片（深度拦截的条目带「深度」标记），以及它自己的访问记录。每条记录右边都有「拦截」与「放行」两个按钮，点任一个都会弹出「应用到…」，可选「仅这个应用」或「所有应用」—— 于是日志里的一行就能变成范围由你决定的规则。

实时与历史

两个页签：现在连着什么，以及每个应用长期以来的尝试次数、拦截次数和最后一次活动时间。

一行变成一条规则

在任意一条访问记录上按「拦截」或「放行」，再选「应用到…」—— 仅这个应用，或所有应用。

筛选、聚合与导出

全部 / 仅拦截 / 仅放通；按时间或按站点；自己加的规则可以逐条移除；详情页可导出记录。

你自己的名单

两种导入方式，最后都会变成和内置模块并列、由你掌控的功能模块。

导入文件

导入 .yaml、.txt 或 .mrs 文件。御流会自动识别类型（域名列表 / IP 列表 / 混合列表 / 完整网址匹配）与动作（拦截或放行），应用之前先让你确认读到了什么。文件导入没有大小上限，32 MB 的上限只适用于导入链接的下载。

导入链接

粘贴订阅地址。只接受 https:// 开头的链接 —— 规则集本身就是防火墙规则，明文下载可能被中途改写。「更新」一键刷新，并显示上次更新时间。

我的拦截与放行

你手动加入的规则都汇总在这张独立卡片里，与模块并列。它刻意不做成一键关闭的开关。空着的时候会告诉你怎么填：打开一个应用，展开它的访问记录，在一条记录上按「拦截」或「放行」。

深度解析

深度解析是可选项，默认关闭。它是御流唯一会读取连接内容的部分，而这只在你装了证书之后才可能 —— 应用内的请求是加密的，装了证书手机才能把它们展示给御流看。证书只留在本机，从不上传。

开启后，判断依据从域名变成 URL 路径，于是同一个主机名下的正文页面和广告位可以区分开。页面上的状态是三态：已开启 / 未开启 / 已暂停；没装证书时会直接说明：「还没生效：ClearDeck 证书尚未安装。」

生效范围
所有应用，或「仅我选中的应用」—— 带搜索与「仅看已选」筛选。
仅在 Wi-Fi 下生效
切到移动数据时，深度解析会自动关闭。
内容检查上限
128 KB / 256 KB / 512 KB / 1 MB，默认 256 KB。超过上限的内容直接放行、不做逐字检查；值越大检查越全但占用内存越高，值越小越省电，但可能漏掉个别大文件里的广告。
证书
「安装证书」会把 cleardeck-ca.crt 存到下载目录，同时打开系统证书页面；移除时到「受信任的凭据 → 用户」里删除。

日常使用

设置一次、之后就不必再想的部分。

随系统启动
「随系统启动」会跳到系统的 VPN 列表；在那里点御流右侧的齿轮，打开「始终开启的 VPN」。之后每次开机隧道自动建立，不用手动点。应用没有开机广播接收器、没有 WakeLock，也没有 AlarmManager／WorkManager 之类的系统调度 —— 隧道靠前台服务维持，不靠持锁。
加密 DNS
域名查询走加密连接。默认地址是 https://223.5.5.5/dns-query，随时可以更换。
访问记录窗口
访问记录保留多少条：100 / 500 / 1000 / 2000，默认 500。窗口越大记录越多，内存占用也越多。
省电模式
一个开关。它让速度显示更新得更慢，并暂停深度解析来省电；开启期间深度链接拦截和「最近活动」记录都会变少。它具体放宽了哪些采样周期，写在隐私页上。
导出

导出访问记录

工具页只有一件事：导出访问记录。它输出 CSV（RFC 4180，UTF-8 带 BOM），文件名形如 cleardeck-access-<主体>-<yyyyMMdd-HHmm>.csv，列名为本地化文本。记录会随防护关闭而清空，需要保留就要先导出。

实测数据（OnePlus 6T / Android 11）：开启防护的 30 分钟里，:tun 进程累计占用 20.67 秒 CPU —— 相当于单核的 1.148% —— 而界面进程几乎不耗 CPU（后台被系统冻结）。这是在一台设备上的测量结果，不是承诺。
